ChromeOS Flex では、「Linux 開発環境」（通称 Linux）を仮想環境で使える。ChromeOS Flex で対応していないアプリは、この Linux にインストールして使うことが出来る。（VSCode や Obsidian など）

- **Linux** : りなくす

## Linux をインストールする

![[ChromeOS Flex Linux をインストール.webm]]

1. 下部右側にある「**時刻表示**」部分をクリックする。
2. 表示されたポップアップの右下にある「**歯車**」（設定）をクリックする。
3. 設定画面の左側メニューの一番下にある「**ChromeOS について**」をクリックする。
4. 右側に表示された「ChromeOS について」画面の一番下にある「Linux 開発環境」項目の「**設定**」ボタンをクリックする。
5. 「Linux 開発環境をセットアップする」画面が開くので、右下にある「**次へ**」ボタンをクリックする。
6. 「ユーサー名」の入力画面が表示されるので、「ユーザー名」を入力し、「**インストール**」ボタンをクリックする。
	  - **ユーザー名**は Linux 開発環境におけるログインIDになるが、複数のIDを使うことはないので短い名前にしておくほうが良い。
	  - **ディスクサイズ**は推奨（10.0GB）のままで良い。これより小さくしてはいけない。
7. 「Linux をインストールしています...」が表示されるので、終了するまでこのまま待つ。
	  - ネット回線の具合により時間かかる場合もある。
8. インストールが終了すると、**ターミナル画面**（黒い画面）が表示される。ターミナル画面に「ユーザー名@penguin:~$」が表示されれば起動完了で、Linux 開発環境が利用できる。

## Linux を終了する

![[ChromeOS Flex Linux を終了.webm]]

1. 画面下部のシェルフに表示されている「**ターミナル**」を右クリックする。
2. 表示されたポップアップの「**Linux をシャットダウン**」をクリックする。
3. Linux が終了し、ターミナル画面が消えて、「Linux 開発環境」画面に戻る。

## Linux を開始する

![[ChromeOS Flex Linux を開始.webm]]

1. 画面下部のシェルフの左側にある「**G**」マークをクリックする。
2. 表示されたポップアップの下の方にある「**ターミナル**」をクリックする。
3. 表示された「Linux 開発環境」画面にある「**penguin**」（ペンギン）をクリックする。
4. するとLinux が起動して、「ユーザー名@penguin:~$」が表示される。
