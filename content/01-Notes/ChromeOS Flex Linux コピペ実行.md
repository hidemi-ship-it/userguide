文字列をコピーして、Linux ターミナルにペースト（貼り付け）し、実行する方法（コピペ実行）を説明する。

## Linux ターミナルでコピペ実行

1. コマンド文字列をコピーする。（文字列を選択して右クリックや、コピーボタンのクリックなどど）
2. Linux ターミナルの上で、**右クリック**する。
3. コマンド文字列が貼り付けられるので、そのまま、キーボードの「Enter」(エンターキー)を押す。
4. すると、貼り付けたられた文字列で表現されるコマンドが実行される。

## 実例

![[ChromeOS Flex Linux コピペ実行.webm]]

1. Linux ターミナルを起動する。
2. ウェブブラウザを起動する。
3. 表示されているrebootコマンドの「コピー」ボタンをクリック。
4. 「Copied!」の表示（すぐ消えるので注意深く）が出ればコピー完了。
5. ターミナルに戻って、ターミナルをクリックしてアクティブにする。
6. **右クリック**して貼り付ける。
7. つづけて、キーボードの「Enter」(エンターキー)を押す。
8. コマンドが実行されその結果、Linux が終了する。
   - reboot(再起動)コマンドなので、終了してしまう。
