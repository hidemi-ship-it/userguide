ChromeOS Flex では、Linux ターミナルの見栄え（文字の大きさなど）を設定できる。

## Linux ターミナルを設定する

![[ChromeOS Flex Linux ターミナルを設定.webm]]

1. ターミナル画面上部の最左タブ（**＞**）をクリックする。
2. 表示された「Linux 開発環境」画面の中ほどにある「**ターミナルの設定**」をクリックする。
3. 「ターミナルの設定」画面が表示されるので、好みの設定をする。ここでは文字サイズを大きく（サイズ：15）してみる。
4. 設定が終わったあとに、最上部の「**×**」をクリックする。
5. 設定画面が閉じるので、「Linux 開発環境」画面（ターミナル画面）にもどり、「ユーザー名@penguin: ~」タブをクリックする。
6. ターミナル画面が表示され、すでに、文字が大きくなっている。
