ChromeOS Flex Linux 開発環境にテキストエディタである mousepad をインストールしておけば設定ファイルの変更に役に立つ。インストールする手順を解説する。

まず先に、[[ChromeOS Flex Linux 日本語環境]] を済ませておく。

## mousepadのインストール

![[ChromeOS Flex Linux mousepadのインストール.webm]]

1. 次のコマンドを実行する。
```
sudo apt install mousepad
```

2. 「Continue? \[Y/n]」が表示され止まったら、Enter(エンターキー)を押す。
3. インストールが終了したら、次のコマンドで mousepad を起動する。
```
mousepad
```
4. 「半角/全角」キーを押すたびに、日本語と英語が切り替わる。
