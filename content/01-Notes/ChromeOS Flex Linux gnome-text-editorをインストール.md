ChromeOS Flex Linux 開発環境にテキストエディタである gnome-text-editor をインストールしておけば設定ファイルの変更に役に立つ。インストールする手順を解説する。

まず先に、[[ChromeOS Flex Linux 日本語環境]] を済ませておく。

## gnome-text-editorのインストール

![[ChromeOS Flex Linux gnome-text-editorのインストール.webm]]

1. 次のコマンドを実行する。
```
sudo apt install gnome-text-editor
```

2. 「Continue? \[Y/n]」が表示され止まったら、Enter(エンターキー)を押す。
3. インストールが終了したら、次のコマンドで gnome-text-editor を起動する。
```
gnome-text-editor
```
4. 「半角/全角」キーを押すたびに、日本語と英語が切り替わる。

## gnome-text-editor（テキストエディター）の起動

![[ChromeOS Flex Linux gnome-text-editorの起動.webm]]

1. 画面最下部にあるシェルフの左側にある「G」をクリックする。
2. 表示されたポップアップの上側にある「Linux アプリ」をクリックする。
3. ポップアップされた「Linux アプリ」の中にある「テキストエディター」をクリックする。
4. gnome-text-editor（テキストエディター）が起動する。
